Light It Up Dashboard

Every Light It Up attendee gets their own dashboard: one login that holds everything about the event, from event-day directions to the replay. Mike designed and built it for This Is It Team, styled to match the event's lightning artwork.

The full Light It Up system

The challenge

After someone registers for an event, the questions start: where do I go, when does it start, how do I watch, where's the replay? Usually the answers are scattered across confirmation emails, social posts and support inboxes.

This Is It Team wanted one place where every attendee, in the room or watching online, could find everything they need before, during and after the event, in their own language.

The approach

Mike designed the dashboard around the attendee's journey, with a simple sidebar of tabs that each answer one question. Each person signs in with their email and a password or an emailed sign-in link, and sees a dashboard personalized to them.

Every page carries the Light It Up banner and the event's purple-to-pink gradient, so it feels like part of the event rather than a separate account page.

The solution

  • Welcome: a personal greeting, an introduction to the This Is It Team experience, and a one-click button to watch the replay.
  • In-Person: everything for event day: date, time, room and address, a Get Directions button, and a campus map showing exactly where ACC North is, plus a step-by-step guide from arrival to the main stage.
  • Live Stream: the event broadcast, shown during the event for virtual attendees.
  • Replay: past event replays, with an event picker so attendees can rewatch any event they have access to.
  • Photos: event photo galleries, organized by event.
  • Shop: a doorway to the This Is It Team store for apparel, gear and business tools.
  • FAQ: searchable answers about tickets, confirmation emails, refunds, payment plans, watching live and live translation.
  • Account & Settings: personal details, a preferred language for live interpretation, every ticket the attendee holds with add-to-calendar links, payment history and password settings.
  • Built for a global audience: the whole dashboard switches between English, Spanish, Portuguese, German, French and Chinese, and a support chat is one click away on every page.

The outcome

Attendees have one link for the whole event. The same dashboard carries across This Is It Team's events, so each person's tickets, replays and settings stay together in a single account.
